# trees-for-growth
trees for growth is a complete website written in react/django

Allows a user to measure the impact of the trees they plant to their respective region.
Also provides a socializing platform since it includes a community feature where people can meet up and make an impact together.

I created this project to help with my understanding of React components, stores and many more frontend features, as well as connecting them to the relevant backend processes.

Previously hosted on https://treesforgrowth.com/ but currently inactive
